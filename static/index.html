Настройки

Все 5 движков реализуют идентичные 10 жёстких и 11 мягких правил. Timefold Python — стабильно, in-process. OR-Tools — многопоточный CP-SAT, лучше на длинных бюджетах. Timefold Kotlin — свежий 2.0 через отдельный JVM-процесс (Quarkus на :9091). Комплексный поиск — четыре acceptor'а (Late Acceptance, Simulated Annealing, Tabu Search, Great Deluge) запускаются параллельно на полный бюджет; берётся лучшее. SolverForge-Legacy — JPype-форк Timefold 1.24 для сравнения.
Критерии остановки солвера
Жёсткий таймаут. По истечении солвер остановится в любом случае.
Положительное число. Солвер остановится, как только мягкая оценка станет не хуже, чем −(это значение) — например, введи 50000, чтобы остановиться при soft ≥ −50 000. Оставь пустым, если не нужно.
