# UniA — синтетический набор «Universal Airlines»

Полномасштабный синтетический набор данных авиакомпании: расписание,
персонал, места экипажа и правила расчёта. Построен так, чтобы
воспроизводить статистическую структуру реальной сети (размер,
топологию, распределения нагрузки и квалификаций) и при этом **не
содержать ни одного реального идентификатора**.

## Состав

| Файл | Что это |
|---|---|
| `payload-unia.json` | канонический набор COSMOS: аэропорты, сотрудники, рейсы, места экипажа, квалификации |
| `source-rules-unia.json` | правила расчёта в машинной форме (`_cos_rules.CosRules`) |
| `pin-catalog-unia.json` | закрепления каталога — обязательные условия, которые расчёт обязан сохранить |

## Размерность

| | |
|---|---:|
| Аэропортов | 73 |
| Рейсов | 3435 |
| Сотрудников | 1344 |
| Мест экипажа | 18 595 |
| Записей о квалификациях | 2567 |
| Горизонт | март 2027 |

Роли мест: `PURS` (старший бортпроводник), `CA` (бортпроводник),
`CA С-cl` (бортпроводник бизнес-класса), `INST` (инструктор).

## Анонимность

Коды и названия аэропортов, номера рейсов, типы воздушных судов и имена
сотрудников — **выдуманные**. Имена сотрудников имеют вид
`UniA Crew 0001`, номера рейсов — `<число>-<ГГГГММДД>-<порядковый>` без
префикса перевозчика.

Проверено машинно: сканирование всех строковых значений набора
(277 067 строк) на коды станций, номера рейсов и названия реальных
перевозчиков дало **ноль находок**.

Генератор набора и карта соответствия «исходное значение → синтетическое»
намеренно не публикуются: карта соответствия — это ключ к обратному
восстановлению, и её раскрытие обесценило бы анонимизацию.

## Как использовать

```bash
.venv/Scripts/python _pairing_builder.py \
    --payload data/unia/payload-unia.json \
    --label UNIA --level 3 --budget-s 3600 \
    --source-rules data/unia/source-rules-unia.json \
    --out unia-pairing.json
```

Либо через интерфейс: «Данные» → «Экземпляры» → «Загрузить и проверить»
(формат «Канонический набор COSMOS»).
