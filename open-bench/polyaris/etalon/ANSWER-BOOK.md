# Книга правильных ответов «Полярис» (по эталону M0)

Справочник для заполнения живой анкеты прогона: на каждый вопрос,
который обязан открыть CDPM по подложенным дефектам, — ответ по
эталону. Формулировка вопроса в живой анкете может отличаться;
сопоставлять по теме и ссылкам на источники.

| Тема (дефект) | Правильный ответ авиакомпании |
|---|---|
| K-01 предел смены: 12:00 или 11:30? | Действует 12:00 (памятка устарела); продление до 13:00 по согласию — верно |
| K-02 месячный кредит: 85 или 80? | 85 часов (строка журнала — устаревшее напоминание) |
| K-03 стыковка в базе: 45 или 50? | 45 минут (решение по инциденту не утверждено) |
| K-04 резерв PLY: 2 или 3? | 2 экипажа (памятка ошибается) |
| A-01 «как правило, не более шести» | Жёсткое ограничение: ровно ≤ 6, исключений нет |
| A-02 «более 4» — единицы | 4 часа |
| A-03 «достаточное время на отдых» | Не правило: информационная фраза, не формализуется |
| A-04 «своевременно» (явка резерва) | Не правило: покрывается вызовом за 2 часа (см. журнал) |
| A-05 «продолжительный отдых» | Не правило: покрывается отдыхом после продлённой смены 14 ч |
| G-01 нормы питания (приложение 2) | Вне контура оптимизации: не формализуется |
| G-02 длительность резервного ожидания | Принять равной норме резервной смены: 10 часов |
| G-03 регламент обменов | Вне контура: обмены сменами в модуль не входят |
| D-01 отдых дома: 12:00 или 12:30? | 12:00 (напоминание в разделе 3 ошибочно) |
| D-02 вызов из резерва: 2 или 3 часа? | 2 часа (архивная строка устарела) |
| Веса целевой функции (3а) | Ночи вне базы 10; стыковки 1/0:30 сверх часа; разрыв смены 20; однородность 5; гарантия смены 4:00 |
| Веса целевой функции (3б) | Справедливость 3; баланс баз 16/64/19 ±3 п.п.; предпочтения 2; стабильность 15; равномерность 2; резерв 1 |
