# Расписание-свидетель набора «Полярис-H0-КИ-окна»

Свидетель — данные сценария, не результат решателя: допустимый ростер по
сбалансированной книге комплекта (12 рейсов в сутки: 10 дневных и ночная
пара, 27 суток, 24 пилота), построенный из замкнутых ротаций без
позиционирования пассажирами, и отрицательные варианты с ровно одним
заведомым нарушением. Ожидание каждого свидетеля берётся из сценария и ВМП.
Генератор — `../build_witness_h0kw.py` (самопроверка по жёстким правилам
ВМП H0; `--write` пишет файлы этого каталога); тест —
`tests/test_h0kw_witness.py`.

| Файл | Книга | Ожидание сертификатора ростеринга |
|---|---|---|
| `witness-nohist-positive.json` / `.xlsx` | `data/ID-H0KW-DATA.xlsx` (без «Истории», умолчание) | «допустимо»: жёстких нарушений нет; истории нет — решение пользователя «продолжить с нулевой историей», окна через границу судятся по допущению |
| `witness-hist-positive.json` / `.xlsx` | `data/ID-H0KW-HIST-DATA.xlsx` (сценарии A/B/C) | «допустимо»: жёстких нарушений нет, три формы окон зелёные с учётом истории |
| `witness-hist-neg-A.json` / `.xlsx` | с «Историей» | ровно одно нарушение VN-091 у H03: ночная ротация 04.09 (PL401 23:30 → PL402) при серии ночных 2 в истории → серия 3 > 2 |
| `witness-hist-neg-B.json` / `.xlsx` | с «Историей» | ровно одно нарушение VN-023 у H07: ротация PL301 04.09 06:00 при конце последней смены 03.09 22:00 → отдых дома 480 < 720 |

Формат — вход сертификатора ростеринга (`vmp/run/roster_certify`): JSON
`{assignments, duties}` (плюс служебные `variant`, `book`, `expectation`,
`expected_violations`, `self_check`) и книга xlsx с листами «Назначения»
(Табельный номер, Рейс, Дата, Аэропорт вылета, Аэропорт прилёта, Время
вылета, Время прилёта, Роль, База приписки, Смена, Перегон) и «Смены»
(Табельный номер, Идентификатор, Начало, Конец, База приписки, Место
отдыха, Согласие на продление). У PL401 «Дата» — дата вылета, прилёт 01:10
следующих суток; «Начало» и «Конец» смены — ISO-время.

## Ротации

Все ротации замкнуты на базу экипажа, перегонов нет, экипаж — КВС + Второй
пилот одной базы (VN-081 должности не различает):

| Ротация | База | Рейсы | Длительность |
|---|---|---|---|
| P1 | PLY | PL101 08:00 → SVG, PL102 10:20 → PLY 11:50 | 230 мин |
| P3 | PLY | PL301 06:00 → SVG 07:30; дневной отдых в SVG 650 мин ≥ 600; PL306 18:20 → PLY 19:50 | две смены одних суток |
| P6 | PLY | PL401 23:30 → SVG 01:10, PL402 02:10 → PLY 03:50 следующих суток | 260 мин, ночная |
| V1 | SVG | PL302 08:20 → PLY 09:50, PL305 15:40 → SVG 17:30 | 550 мин |
| G1 | GRT | PL304 13:10 → PLY, PL201 19:00 → GRT 20:40 | 450 мин |
| G2 | GRT | PL202 07:20 → PLY, PL303 10:40 → GRT 12:20 | 300 мин |

PLY — 6 экипажей, цикл 6 суток (экипаж X: P1 в день X, P6 в день X+2, P3 в
день X+4); каждые сутки заняты 4 экипажа PLY (P1, P3, P6 этих суток и P6
предыдущих), свободны 2 — резерв VN-060 ровно по норме. SVG — V1 по кругу
из 3 экипажей (свободны 2). GRT — 3 экипажа, цикл 6 суток [G2, G2, G1, G1,
—, —] со сдвигом фаз (переход G1 → G2 назавтра исключён: отдых был бы 640 <
720). Дневной отдых P3 в SVG внутри одних суток — не ночёвка (контракт
цены: ночёвка — отдых вне базы до других суток).

Сценарии книги с историей: H03 (экипаж c0, серия ночных 2) — первая смена
P1 04.09 08:00, ночная только 06.09; H07 (экипаж c5, конец последней смены
03.09 22:00) — первая смена P1 09.09; H11 (экипаж c3) — выходных сентября
9 ≥ 8 с учётом трёх отработанных суток до среза.

## Самопроверка генератора

По каждому пилоту в хронологии: покрытие рейсов (ровно 2 действующих
пилота, перегонов нет), допуски на дату рейса (VN-070), непрерывность
маршрута, стыковки ≥ 45 мин (VN-020), смена ≤ 720 мин (VN-010), отдых
между сменами ≥ 720 дома / ≥ 600 вне базы, включая отдых от конца последней
смены истории (VN-023/024), серия ночных ≤ 2 с учётом истории (VN-091),
непрерывный отдых ≥ 36 ч в каждом окне скользящего домена — любые 10080
минут подряд, проверка во всех точках разрыва; судимый домен от конца
последней смены истории (без истории — от начала горизонта) до границы
горизонта, окна за границей считаются несудимыми (VN-092), выходных месяца
≥ 8 при закрытом месяце (VN-093), резерв по базам за каждые сутки
(VN-060). Ночная программа книги должна быть замкнутой внутри горизонта:
сироту PL402 первых суток или PL401 последних свидетель называет
нарушением «книга».
