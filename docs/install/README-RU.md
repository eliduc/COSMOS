# Установка и удаление COSMOS

Комплект рассчитан на неспециалиста: программа сама обследует
компьютер, сама принимает всё, что можно вывести из фактов, и
спрашивает только то, за что отвечает человек. Диалог идёт на одном из
пяти языков — английском, арабском, узбекском, казахском, русском.

## Что в комплекте

| Файл | Для чего |
|---|---|
| `УСТАНОВИТЬ-COSMOS.cmd` (он же `INSTALL-COSMOS.cmd`) | то, на чём щёлкают, чтобы поставить |
| `УДАЛИТЬ-COSMOS.cmd` (он же `UNINSTALL-COSMOS.cmd`) | то, на чём щёлкают, чтобы удалить |
| `install_bootstrap.ps1` | подготовка: находит Python и git, при согласии ставит недостающее |
| `uninstall_bootstrap.ps1` | подготовка удаления: находит Python и сам деинсталлятор |
| `install_cosmos.py` | установщик: обследование → замысел → установка → проверка |
| `uninstall_cosmos.py` | удаление установки |
| `UNINSTALL-PLAN-RU.md` | обоснование: почему удаление устроено именно так |

Пары имён — одно и то же: латинское имя для площадок, где кириллицу в
имени файла не прочитают.

## Установка

Щёлкнуть по `УСТАНОВИТЬ-COSMOS.cmd`. Первый вопрос — язык; дальше весь
диалог идёт на нём, и он же станет языком самой программы. Второй
вопрос — куда ставить. На всё остальное отвечают номером варианта или
клавишей Enter: у каждого вопроса есть безопасный ответ по умолчанию.

О чём спросят по существу:

- **разрешены ли облачные модели ИИ** на этой площадке. Ответ «нет» —
  подсказки ИИ готовит только локальная модель. Ответ «да» — облако
  допускается для наборов, помеченных как открытые данные; наборы
  заказчика помечены «только локально» и в облако не уходят никогда;
- **локальная модель** (сервер Ollama). Если она не отвечает по обычному
  адресу, установщик спросит адрес — сервер бывает на другой машине или
  порту. Если моделей несколько, спросит, какой пользоваться. Если
  локальной модели нет вовсе, скажет об этом прямо: подсказки ИИ по
  данным заказчика работать не будут, но сама программа работоспособна —
  расчёты пейринга и ростеринга от моделей ИИ не зависят;
- **как люди будут входить** — по паролю (работает сразу) или по
  одноразовому коду через Cloudflare Access;
- **с каких компьютеров открывать** программу — только с этого или со
  всех в местной сети;
- **ставить ли JDK и Maven**, если их нет: они нужны для расчёта
  ростеринга и кладутся в каталог установки, система не меняется.

В конце установщик показывает **пароль для входа**, раздел «как
запускать программу» и путь к **журналу установки**:

```
журнал установки (нужен для удаления): C:\Users\<вы>\AppData\Local\cosmos-install\install-<дата>.jsonl
```

Рядом с журналом ложится **опись установленного** (`manifest-<дата>.jsonl.gz`) —
перечень всего, что установка оставила после себя. Оба файла нужны
удалению; они лежат в вашем профиле и переживают удаление самой
программы. Читать их не нужно.

Последним вопросом установщик предложит **запустить COSMOS сразу**. При
согласии он поднимает программу, дожидается её отклика и открывает в
браузере — браузер открывается только тогда, когда программа
действительно отвечает.

## Как запускать потом

- **Запуск:** двойной щелчок по `START-COSMOS.cmd` в каталоге установки
  (обычно `C:\cosmos`). Он поднимает программу и открывает браузер.
- **Адрес:** `http://127.0.0.1:8090`; если вы разрешили доступ из сети —
  с других компьютеров по адресу этой машины, например
  `http://192.168.1.50:8090`.
- **Остановка:** закрыть окно, которое открылось при запуске.
- **Ростеринг (этап 2)** — отдельная служба: `run-solver.cmd`, порт 9096.
- **Модуль обработки данных авиакомпании** — отдельная служба:
  `run-cdpm.cmd`, порт 8095, адрес `http://127.0.0.1:8095`. Модуль
  превращает документы авиакомпании (правила, книги данных) в
  постановку задачи для расчёта. Он слушает только эту машину; чтобы
  открыть его из сети, запустите с ключом `--host 0.0.0.0` —
  собственного входа по паролю у модуля нет, поэтому такой запуск
  уместен только в защищённой сети.
- **Каталог шаблонов** — отдельная служба: `run-catalog.cmd`, порт 8105,
  адрес `http://127.0.0.1:8105`; на установке заказчика — только
  просмотр (правки и выпуск версий каталога делаются у владельца).
  Если службы нет в вашем комплекте, пускового файла установка не
  создаёт и об этом говорит.
- **Забыли пароль:** удалить `webapp\config\auth.json` и запустить
  программу заново — она создаст новый.

## Удаление

Щёлкнуть по `УДАЛИТЬ-COSMOS.cmd`. Программа сначала пройдёт все
проверки **вхолостую** и покажет, что именно удалит, затем спросит
согласие. Пока не ответите «да», ничего не меняется; после «да» все
проверки выполняются заново — уже перед самим удалением.

Тем, кому удобнее из командной строки, доступно то же самое напрямую:

```bash
C:\Python314\python.exe uninstall_cosmos.py
```

```bash
C:\Python314\python.exe uninstall_cosmos.py --apply
```

Полезные ключи: `--list` — какие установки найдены на этом компьютере;
`--target <каталог>` — если установок несколько; `--lang <код>` — язык
вывода (по умолчанию берётся язык, выбранный при установке).

Деинсталлятор приезжает и вместе с самой программой (`C:\cosmos\
uninstall_cosmos.py`), так что удалить установку можно и без комплекта:
запускать его прямо оттуда безопасно — он сам уходит из удаляемого
каталога.

Для удаления правила сетевого экрана и задачи автозапуска нужны **права
администратора**: если они есть, а прав нет, программа честно
остановится и скажет об этом.

### Что удаление делает и чего не делает

Удаляется только то, что создала установка: каталог программы, каталог
данных (если он пуст, как его создала установка), пусковые файлы,
правило сетевого экрана и задача автозапуска — если их заводила эта
установка, — а также процессы, оставшиеся от неё.

Не удаляется принципиально: то, что стояло на компьютере до установки
(Java, Python, git и прочее); общие ресурсы — кеш pip и репозиторий
Maven, которыми пользуются другие проекты; ключи SSH, потому что их
могли уже раздать по репозиториям. Всё это перечисляется в выводе, а не
умалчивается.

При любой неясности удаление **останавливается и показывает объект**, а
не решает за вас. Каждая проверка печатает, сколько объектов
рассмотрела: «нарушений нет» без числа рассмотренных за проверку не
считается.

### Откуда такая дотошность

Опись, снятая установщиком, позволяет сверить **каждый** объект дерева.
Без неё пришлось бы принимать на веру целые поддеревья — клон с
историей, окружение python, набор инструментов, — а это шестнадцать
тысяч объектов из девятнадцати; чужой файл, перенесённый туда
владельцем, остался бы незамеченным и погиб бы вместе с установкой.
Теперь каждый объект либо значится в описи, либо порождён работой самой
программы (журналы, кеши, рабочие файлы), либо признаётся посторонним —
и тогда снос останавливается.

### Если установка прервалась

Ничего страшного: журнал пишется по ходу дела и с немедленной записью
на диск, поэтому в нём точно указано, что успело создаться. Удаление
уберёт ровно это. Журнала нет вовсе (установка сделана прежней версией)
— удаление обойдётся признаками: маркером в пусковом файле и сверкой
дерева; оно скажет об этом прямо, потому что такой путь менее точен.

## Языки

Тексты диалога лежат отдельными файлами по языкам в репозитории:
`crew-demo/handoff/i18n-installer/messages-<язык>.json`. Русский —
исходник; остальные повторяют его ключ в ключ.

Чтобы поправить формулировку или добавить язык: изменить нужный файл и
собрать заново —

```bash
C:\Python314\python.exe crew-demo\handoff\i18n-installer\embed_i18n.py
```

Сборка вкладывает словари прямо в `install_cosmos.py` и
`uninstall_cosmos.py` (оба файла должны работать по одному, без
внешних словарей) и **отказывается собирать**, если в каком-то языке не
хватает ключей или разошлось число подстановок — иначе строка упала бы
уже у заказчика. После сборки скопируйте оба файла в этот комплект.
