# COSMOS бағдарламасын орнату және жою

Жинақ маман емес адамға арналған: бағдарлама компьютерді өзі
тексереді, фактілерден шығаруға болатынның бәрін өзі шешеді, тек адам
жауап беретін нәрсені ғана сұрайды. Сұрақ-жауап бес тілдің бірінде
жүреді — ағылшын, араб, өзбек, қазақ, орыс тілдерінде.

## Жинақтың құрамы

| Файл | Не үшін керек |
|---|---|
| `INSTALL-COSMOS.cmd` (баламалы атауы — `УСТАНОВИТЬ-COSMOS.cmd`) | орнату үшін шертетін файл |
| `UNINSTALL-COSMOS.cmd` (баламалы атауы — `УДАЛИТЬ-COSMOS.cmd`) | жою үшін шертетін файл |
| `install_bootstrap.ps1` | дайындық: Python мен git-ті табады, келісім берілсе жоқтарын орнатады |
| `uninstall_bootstrap.ps1` | жоюға дайындық: Python-ды және жою бағдарламасының өзін табады |
| `install_cosmos.py` | орнатқыш: компьютерді тексеру → жоспар → орнату → тексеру |
| `uninstall_cosmos.py` | орнатылымды жою |
| `UNINSTALL-PLAN-RU.md` | негіздеме: жою неге дәл осылай құрылған |

Атау жұптары — бір ғана файлдың екі атауы: латын әріптерімен жазылған
атау файл атауындағы кириллицаны оқи алмайтын компьютерлер үшін керек.

## Орнату

`INSTALL-COSMOS.cmd` файлын шерту керек. Бірінші сұрақ — тіл; әрі қарай
барлық сұрақ сол тілде қойылады, әрі сол тіл бағдарламаның тілі болады.
Екінші сұрақ — қайда орнату керек. Қалған сұрақтарға нұсқаның нөмірін
теру арқылы немесе Enter пернесі арқылы жауап беріледі: әр сұрақтың
қауіпсіз әдепкі жауабы бар.

Мәні бойынша не сұралады:

- **бұлттағы жасанды интеллект модельдеріне рұқсат бар ма** осы
  компьютерде. «Жоқ» деген жауап — жасанды интеллект кеңестерін тек
  жергілікті модель дайындайды. «Иә» деген жауап — бұлт «ашық деректер»
  деп белгіленген жиынтықтар үшін ғана рұқсат етіледі; тапсырыс
  берушінің жиынтықтары «тек жергілікті» деп белгіленген және бұлтқа
  ешқашан жіберілмейді;
- **жергілікті модель** (Ollama сервері). Егер ол әдеттегі мекенжай
  бойынша жауап бермесе, орнатқыш мекенжайды сұрайды — сервер басқа
  компьютерде немесе басқа портта болуы мүмкін. Модель бірнешеу болса,
  қайсысын пайдалану керегін сұрайды. Жергілікті модель мүлдем болмаса,
  бұл туралы тура айтады: тапсырыс берушінің деректері бойынша жасанды
  интеллект кеңестері жұмыс істемейді, бірақ бағдарламаның өзі жұмысқа
  қабілетті — ұшу тізбектерін құру мен экипаж кестесін құру есептеулері
  жасанды интеллект модельдеріне тәуелді емес;
- **адамдар бағдарламаға қалай кіреді** — құпия сөзбен (бірден жұмыс
  істейді) немесе Cloudflare Access арқылы келетін бір реттік кодпен;
- **бағдарламаны қай компьютерлерден ашуға болады** — тек осы
  компьютерден немесе жергілікті желідегі барлық компьютерден;
- **JDK мен Maven орнату керек пе**, егер олар жоқ болса: олар экипаж
  кестесін құру есебі үшін қажет және орнату каталогына салынады, жүйе
  өзгертілмейді.

Соңында орнатқыш **бағдарламаға кіру құпия сөзін**, «бағдарламаны қалай
іске қосу керек» деген бөлімді және **орнату журналына** апаратын жолды
көрсетеді:

```
орнату журналы (бағдарламаны жою үшін қажет): C:\Users\<сіз>\AppData\Local\cosmos-install\install-<күні>.jsonl
```

Журналдың қасына **орнатылғандардың тізімдемесі**
(`manifest-<күні>.jsonl.gz`) қойылады — орнату өзінен кейін қалдырғанның
бәрінің тізімі. Екі файл да жою үшін қажет; олар сіздің профиліңізде
жатады және бағдарламаның өзі жойылғаннан кейін де сақталады. Оларды
оқудың қажеті жоқ.

Соңғы сұрақ ретінде орнатқыш **COSMOS бағдарламасын бірден іске
қосуды** ұсынады. Келісім берілсе, ол бағдарламаны іске қосады, оның
жауабын күтеді және браузерде ашады — браузер бағдарлама шынымен жауап
бергенде ғана ашылады.

## Кейін қалай іске қосу керек

- **Іске қосу:** орнату каталогындағы (әдетте `C:\cosmos`)
  `START-COSMOS.cmd` файлын екі рет шерту. Ол бағдарламаны іске қосады
  және браузерді ашады.
- **Мекенжайы:** `http://127.0.0.1:8090`; желіден қолжетімділікке рұқсат
  берген болсаңыз — басқа компьютерлерден осы машинаның мекенжайы
  бойынша, мысалы `http://192.168.1.50:8090`.
- **Тоқтату:** іске қосқанда ашылған терезені жабу.
- **Экипаж кестесін құру (2-кезең)** — бөлек қызмет: `run-solver.cmd`,
  9096 порты.
- **Авиакомпания деректерін өңдеу модулі** — бөлек қызмет:
  `run-cdpm.cmd`, 8095 порты, мекенжайы `http://127.0.0.1:8095`. Модуль
  авиакомпания құжаттарын (ережелер, деректер кітаптары) есептеуге
  арналған есеп қойылымына айналдырады. Ол тек осы компьютерді
  тыңдайды; желіге ашу үшін `--host 0.0.0.0` кілтімен іске қосыңыз —
  модульдің өз кіру жүйесі жоқ, сондықтан мұны тек қорғалған желіде
  жасаңыз.
- **Шаблондар каталогы** — бөлек қызмет: `run-catalog.cmd`, 8105 порты,
  мекенжайы `http://127.0.0.1:8105`; тапсырыс берушінің орнатуында —
  тек қарау (түзетулер мен нұсқаларды шығару иесінде жасалады). Егер
  қызмет сіздің жинағыңызға кірмесе, орнату оның іске қосу файлын
  жасамайды және бұл туралы айтады.
- **Құпия сөзді ұмытсаңыз:** `webapp\config\auth.json` файлын жойып,
  бағдарламаны қайта іске қосу керек — ол жаңасын жасайды.

## Жою

`UNINSTALL-COSMOS.cmd` файлын шерту керек. Бағдарлама алдымен барлық
тексеруді **сынақ жүрісімен** орындап, нақты нені жоятынын көрсетеді,
содан кейін келісім сұрайды. «Иә» деп жауап бермейінше, ешнәрсе
өзгермейді; «иә» дегеннен кейін барлық тексеру қайтадан орындалады —
енді жоюдың дәл алдында.

Пәрмен жолымен жұмыс істеу ыңғайлы болса, дәл сол әрекеттерді тікелей
орындауға болады:

```bash
C:\Python314\python.exe uninstall_cosmos.py
```

```bash
C:\Python314\python.exe uninstall_cosmos.py --apply
```

Пайдалы кілттер: `--list` — осы компьютерден қандай орнатылымдар
табылды; `--target <каталог>` — орнатылым бірнешеу болса; `--lang <код>`
— шығатын мәтіннің тілі (әдепкіде орнату кезінде таңдалған тіл алынады).

Жою бағдарламасы бағдарламаның өзімен бірге де келеді (`C:\cosmos\
uninstall_cosmos.py`), сондықтан орнатылымды жинақсыз да жоюға болады:
оны тікелей сол жерден іске қосу қауіпсіз — ол жойылатын каталогтан өзі
шығып кетеді.

Желіаралық қалқан ережесі мен өздігінен іске қосылу тапсырмасын жою
үшін **әкімші құқығы** керек: олар бар болып, ал құқық жоқ болса,
бағдарлама шынын айтып тоқтайды және бұл туралы хабарлайды.

### Жою нені істейді және нені істемейді

Тек орнату жасаған нәрсе ғана жойылады: бағдарлама каталогы, деректер
каталогы (ол орнату жасаған күйінде бос болса), іске қосу файлдары,
желіаралық қалқан ережесі мен өздігінен іске қосылу тапсырмасы — оларды
осы орнатылым жасаған болса, — сондай-ақ содан қалған процестер.

Принципті түрде жойылмайды: орнатуға дейін де компьютерде болған нәрсе
(Java, Python, git және басқалары); ортақ ресурстар — басқа жобалар
пайдаланатын pip кеші мен Maven репозиторийі; SSH кілттері, өйткені
оларды репозиторийлерге таратып үлгерген болуы мүмкін. Мұның бәрі
шығатын мәтінде тізіп көрсетіледі, үндемей қалдырылмайды.

Кез келген түсініксіздікте жою **тоқтайды және нысанды көрсетеді**,
сіздің орныңызға шешім қабылдамайды. Әр тексеру қанша нысанды қарағанын
басып шығарады: қаралған нысан саны көрсетілмеген «бұзушылық жоқ» деген
қорытынды тексеру болып саналмайды.

### Мұндай мұқияттылық неден шыққан

Орнатқыш жасаған тізімдеме ағаштағы **әр** нысанды салыстыруға
мүмкіндік береді. Онсыз тұтас ішкі ағаштарды — тарихымен бірге көшіріп
алынған репозиторийді, python ортасын, құралдар жиынтығын — сеніммен
қабылдауға тура келер еді, ал бұл он тоғыз мың нысанның он алты мыңы;
иесі сол жерге ауыстырып салған бөгде файл байқалмай қалып,
орнатылыммен бірге жойылып кетер еді. Енді әр нысан не тізімдемеде
тұрады, не бағдарламаның өз жұмысынан пайда болған (журналдар, кештер,
жұмыс файлдары), не бөгде деп танылады — сонда жою тоқтайды.

### Егер орнату үзіліп қалса

Қорқынышты ештеңе жоқ: журнал жұмыс барысында әрі бірден дискіге
жазылып отырады, сондықтан онда не жасалып үлгергені дәл көрсетілген.
Жою дәл соны алып тастайды. Журнал мүлдем болмаса (орнатуды бұрынғы
нұсқа жасаған), жою жанама белгілермен шектеледі: іске қосу файлындағы
белгімен және каталогтар ағашын салыстырумен; ол бұл туралы тура
айтады, өйткені бұл жолдың дәлдігі төмен.

## Тілдер

Сұрақ-жауап мәтіндері репозиторийде тілдер бойынша бөлек файлдарда
жатыр: `crew-demo/handoff/i18n-installer/messages-<тіл>.json`. Орыс
тіліндегі файл — бастапқы нұсқа; қалғандары оны кілтпе-кілт қайталайды.

Тұжырымды түзету немесе жаңа тіл қосу үшін керекті файлды өзгертіп,
қайта жинау керек —

```bash
C:\Python314\python.exe crew-demo\handoff\i18n-installer\embed_i18n.py
```

Жинақтау сөздіктерді тікелей `install_cosmos.py` және
`uninstall_cosmos.py` файлдарының ішіне салады (екі файл да сыртқы
сөздіксіз, жеке-дара жұмыс істеуге тиіс) және қандай да бір тілде
кілттер жетіспесе немесе қойылатын мәндердің саны сәйкес келмесе,
**жинақтаудан бас тартады** — әйтпесе жол тапсырыс берушінің өзінде
істен шығар еді. Жинақтағаннан кейін екі файлды да осы жинаққа көшіріп
қойыңыз.
