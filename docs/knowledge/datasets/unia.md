# UniA (v23)

- Назначение: замена исходного проприетарного набора для облачных
  прогонов; создан по публикуемому отпечатку (37 агрегатов,
  k-подавление), данные первоисточника не использовались напрямую.
- v23 = v16 + 93 сдвига (core-patches-v21) + окна допусков у всех
  сотрудников + двойные навыки (CA+PURS ×104, TRN+INST ×12) + доктор
  пин-смен: конструктивно достигнуты 0hard/0soft, 0 незакрытых,
  0 нарушений на этапе 2.
- Артефакты: `crew-demo-data/sintez/unia/` (payload, пин-каталог,
  правила источника + отпечаток, условия расчёта, квалификация,
  сравнение приёмки, таблицы методов).
- Генератор: детерминированный, живёт в закрытом контуре исходного
  набора (вне репозитория).

Память процесса: узел `sintez-unia` (история решений и цена
выполнимости — отпечаток 232/327 с объявленными натягами).
