# Развёртывание

- [Контуры и текущее состояние](contours.md)

Процедура (проверенная): бандл `git bundle create … main --not <prev>` →
scp на legion → PAUSE площадки → fetch+ff → kill порта → снять PAUSE →
сторож поднимает (~2 мин) → верификация (HEAD, 401, маркеры статики).
Любая правка статики требует Purge Everything в панели (зонный TTL 4 ч).

Чек-лист портов раската (после шага 5 каталога, 08.09.2026). Гасятся и
зондируются ТРИ порта площадки, а не один, — по [таблице портов
служб](contours.md):

| Площадка | Гашение (порты) | Зонды |
|---|---|---|
| Test | 8092, 8095, 8105 | `/api/scenarios` = 401, `/api/runs` = 200, `/healthz` = 200 |
| Stage | 8091, 8096, 8106 | те же три |
| Prod | 8090, 8097, 8107 | те же три |

Порт панели CDPM гасится только при дельте `cdpm/**` или
`cdpm-ui/**`, порт службы каталога — при дельте `catalog/**`,
`template_catalog/**`, `catalog_service/**` или `catalog-ui/**`
(`final-report/EDINAYA-VERSIYA-CDPM/tools/gen_mid_deploy.py`). Службы
каталога на площадке может не быть (`run-catalog.cmd` не установлен) —
тогда её стоп и зонд пропускаются словами, а не молча.

Проба каталога шаблонов после раската (шаг 7 каталога, часть CDPM,
08.09.2026): в venv каждой площадки — `python -m cdpm.catalog_bridge`
(ожидание: код 0 и строка `CATALOG OK <версия> <отпечаток>
warnings=N <путь>`; код 2 = `REFUSED`, панель будет отказывать словами
на каждом прогоне) плюс `GET /api/catalog` панели контура (ожидание
`ok: true`). Версия и первые 12 знаков отпечатка обязаны совпадать на
всех площадках и с головой раската. Проба встроена в генератор среднего
раската отдельной строкой после перезапуска и в проверку установки
(`install_cosmos.py`, строка отчёта «мост CDPM: каталог …»).
