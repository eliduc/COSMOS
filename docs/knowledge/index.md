# Каталог знаний COSMOS

Формат: [Open Knowledge Format v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog/tree/main/okf)
— markdown-файлы с YAML-шапкой, ссылки образуют граф. Правила каталога:

- **один завершённый пакет работ = один узел** (что сделано, коммит,
  площадки, остатки, ссылки);
- узлы НЕ дублируют документы `final-report/` — ссылаются на них как на
  `resource`;
- **никаких данных заказчика** — только описания, хэши и пути;
- вторая половина графа — постоянная память ассистента
  (`~/.claude/projects/.../memory/`, те же OKF-поля): каталог — про
  проект, память — про процесс и уроки.
