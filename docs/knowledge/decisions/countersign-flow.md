# Контрподпись как гейт (2026-08-07, 6d94ccd)

- **Контекст**: гейт контрподписи существовал в фазах, но рабочего пути
  «токен → фаза» не было: интерфейс токен не принимал, статус
  переключался, фаза молча умирала.
- **Решение**: веб-действие Stage/Prod спрашивает токен
  (`python tools/countersign.py --id … --sha … --phase …`) и проверяет
  его ДО смены статуса; гейт внутри фазы — вторая линия; телеграм-кнопка
  продвижения отвечает подсказкой пути (кнопка токен передать не может).
- **Мотив**: подпись привязана к тройке «правка, срез, фаза» — секрет
  держит человек, автоматика не выписывает подтверждение себе.
- **Следствия**: автономное продвижение невозможно по построению;
  независимость гейта ограничена, пока секрет на том же хосте
  (отсрочка INV-CAND-05).
