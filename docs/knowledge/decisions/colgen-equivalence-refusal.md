# Отказ colgen на равнозначных станциях (2026-08-07, 6d94ccd)

- **Контекст**: отсрочка №1 аудита R10 — второй движок не получал правил
  источника; их равнозначные станции меняют пространство этапа 1, а
  формулировка движка их не выражает.
- **Решение**: числовые пределы источника применяются (и явно едут в
  mp-воркеры); равнозначные станции — ОТКАЗ всегда, не только в строгом
  режиме; такие наборы считает построитель цепочек (уровни 1–2).
- **Мотив**: тихое игнорирование дало бы каталог другой постановки под
  правильным отпечатком — ровно класс дефектов, который закрывал весь
  пакет. Хирургия proof-grade прайсеров ради эквивалентности не
  оправдана риском.
- **Следствия**: `INV-RULES-02` закрыт честно; тест
  `test_colgen_refuses_station_equivalence` пинит отказ.
